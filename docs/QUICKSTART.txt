==================================================================
 Discord Quest Auto-Completer (Unified Dual-Engine Standalone)
==================================================================

QUICK START GUIDE:

1. Prerequisite:
   - Make sure your official Discord Desktop client is open and logged into your account.

2. Configuration:
   - Copy or rename `.token.example` to `.token`.
   - Paste your Discord authorization token into `.token`.
   - Alternatively, you can pass `-token <your_token>` via terminal or set the DISCORD_TOKEN environment variable.

3. Run the application:
   - On Windows: Run `discord-quest-completer.exe`
   - On Linux: Run `chmod +x discord-quest-completer && ./discord-quest-completer`

4. Options:
   - `-dry-run`: View all quests and application resolutions without enrolling or running games.
   - `-auto-accept=false`: Disable automatic enrollment in newly available quests.
   - `-poll=60s`: Set custom polling interval.
   - `-proxy` / `-proxy-file`: Sweep quests from regional exit IPs, e.g.
     `-proxy "us=socks5://127.0.0.1:1080"` or a file with one `CODE=URL` per line.
     Quest eligibility follows the request IP, so this is how region-locked quests
     become visible. The local IP is always swept first and results are unioned.
   - `-region`: `all` (local + every configured proxy), `direct`, `full`, or a
     comma list of proxy/country codes (`us,br,jp`).
   - `-locale-sweep`: `off` (default), `trio`, `all` — language-only probes, kept
     for experiments; they do not change quest eligibility.
   - `-sweep-pacing=3s` / `-sweep-attempts=3`: Discovery pacing and retry budget.
     Discord rate-limits `/quests/@me` aggressively; the engine adapts automatically.
